Visual SML (ViSML)

            
A block-based Standard ML environment.

          

          
        

        

          
Visual SML is a Blockly-based IDE for composing SML programs visually and generating textual Standard ML code.

          

            
Version

            
5.0.0

            
Technology

            
TypeScript, webpack, Blockly 12

Usage

          
        

        

          
    
            
  1. Click or drag a block from the left toolbox into the workspace.
    2. 
            
  2. Connect blocks with matching connector shapes to build SML declarations and expressions.
    3. 
            
  3. Read or edit the Standard ML in the Code panel — edits are parsed back into blocks as you type.
    4. 
            
  4. Parse errors appear in the Diagnostics panel (Ctrl+J); click one to jump to it.
    5. 
          

          
Press Ctrl+Shift+P for the command palette.
